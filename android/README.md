# Android module

## Run

Open the `android` directory in Android Studio, use JDK 17, and run the `app` configuration on an Android device or emulator.

## Prototype behavior

- Six fixed umbrella slots
- Borrow and return buttons
- Red/green slot status text
- Simulated fingerprint login button
- Local hardware actions are currently UI placeholders
